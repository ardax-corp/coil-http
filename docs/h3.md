# HTTP/3 (stub)

HTTP/3 is **not implemented**. Entry points in `http::h3` return `HttpError::NotSupported`.

## Strategy (when QUIC lands)

| Layer | Plan |
|-------|------|
| Transport | `io::net::quic` virtual module (UDP, TLS 1.3 integrated) |
| Client pool | Key by QUIC connection ID + host |
| Server | One QUIC listener, HTTP/3 streams per request |
| Discovery | `Alt-Svc` header from H1/H2 servers |

## Interim

Use HTTP/1.1 or wait for ALPN + HTTP/2 ([h2.md](h2.md)) before HTTP/3.
