# HTTP/2 (M5)

TLS **ALPN** is available on [coil-tls](https://github.com/ardax-corp/coil-tls) (`alpn: "h2"` on `tls::{client,server}::enable`).

Frame header encode/decode lives in `http::h2` (`encode_frame` / `decode_frame`, connection preface). Payload codecs cover SETTINGS (6-byte identifier/value pairs; ACK is empty), WINDOW_UPDATE (4-byte increment, zero rejected), and GOAWAY (last-stream-id + error code). `headers_frame` / `headers_from_frame` wrap static-table HPACK from `http::hpack`. The static table is a compact subset of Appendix A (at least `:method` GET/POST, `:path` `/`, `:scheme` https, `:status` 200, `content-type`, `content-length`).

`H2Session` in `http::h2_session` is an in-memory server view of a client byte buffer. `feed` consumes the 24-byte connection preface, then frames via `decode_frame`. The first frame must be SETTINGS on stream 0; a non-ACK SETTINGS is answered with SETTINGS ACK (flag 0x1, empty payload) on `drain`. HEADERS on odd stream ids store decoded names/values; DATA on those streams accumulates until END_STREAM. Two streams can be interleaved in one buffer. DATA/HEADERS on stream 0 or even client stream ids are `BadResponse`. WINDOW_UPDATE is accepted (increment 0 still fails in the codec). Huffman, the dynamic table, and PUSH_PROMISE are still later.

Cleartext **prior knowledge** (RFC 7540 §3.4) is on the wire for a single GET. `h2_prior_knowledge_get` builds the client preface + empty SETTINGS + stream-1 HEADERS (`:method` GET, `:path`, `:scheme`, `:authority`) with END_HEADERS|END_STREAM. `h2_connect("http://…")` TCP-connects, writes that, then reads frames (`h2_read_frame` / `frame_wire_len`) until stream 1 ends; status comes from `:status` (default 200) and the body from DATA. `https` is `HttpError::NotSupported` (no ALPN query on the package yet). `h2_serve_once` on a bound `http::server::Server` accepts one TCP connection, feeds bytes into `H2Session`, ACKs SETTINGS, and answers stream 1 with HEADERS `:status` 200 plus DATA `ok` and END_STREAM. `h2_serve` (TLS/ALPN) stays `NotSupported`. Socket loopback is `examples/h2_loopback.hy` (`coil test` cannot spawn threads).

## Roadmap

1. Client/server negotiate `h2` via ALPN (open)
2. Shared framing layer in `src/http/h2.hy` (frame header, preface, SETTINGS / WINDOW_UPDATE / GOAWAY / HEADERS: done)
3. HPACK static table (`src/http/hpack.hy`: done)
4. Multiplexed requests per TLS connection (`H2Session` in-memory: done; cleartext prior-knowledge GET: done; TLS still open)
5. Fallback to HTTP/1.1 when ALPN does not select `h2`

See the [coil-http Linear project](https://linear.app/ardax/project/coil-http-e81f48ac1d8b) M5 milestone.
