# HTTP/2 (M5)

TLS **ALPN** is available in coil-lang (`alpn: "h2"` on `io::net::tls::{client,server}::enable`).

Frame header encode/decode lives in `http::h2` (`encode_frame` / `decode_frame`, connection preface). Payload codecs cover SETTINGS (6-byte identifier/value pairs; ACK is empty), WINDOW_UPDATE (4-byte increment, zero rejected), and GOAWAY (last-stream-id + error code). `headers_frame` / `headers_from_frame` wrap static-table HPACK from `http::hpack`. The static table is a compact subset of Appendix A (at least `:method` GET/POST, `:path` `/`, `:scheme` https, `:status` 200, `content-type`, `content-length`). Dynamic table, Huffman, and stream multiplexing are still later; `h2_connect` / `h2_serve` still return `HttpError::NotSupported`.

## Roadmap

1. Client/server negotiate `h2` via ALPN
2. Shared framing layer in `src/http/h2.hy` (frame header, preface, SETTINGS / WINDOW_UPDATE / GOAWAY / HEADERS: done)
3. HPACK static table (`src/http/hpack.hy`: done)
4. Multiplexed requests per TLS connection
5. Fallback to HTTP/1.1 when ALPN does not select `h2`

See the [coil-http Linear project](https://linear.app/ardax/project/coil-http-e81f48ac1d8b) M5 milestone.
