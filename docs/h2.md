# HTTP/2 (M5)

TLS **ALPN** is available in coil-lang (`alpn: "h2"` on `io::net::tls::{client,server}::enable`).

Frame header encode/decode lives in `http::h2` (`encode_frame` / `decode_frame`, connection preface). HPACK and stream multiplexing are **not** on the wire yet; `h2_connect` / `h2_serve` still return `HttpError::NotSupported`.

## Roadmap

1. Client/server negotiate `h2` via ALPN
2. Shared framing layer in `src/http/h2.hy` (frame header + preface: done)
3. Multiplexed requests per TLS connection
4. Fallback to HTTP/1.1 when ALPN does not select `h2`

See the [coil-http Linear project](https://linear.app/ardax/project/coil-http-e81f48ac1d8b) M5 milestone.
